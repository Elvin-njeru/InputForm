2.1 What is a Spinner?

An Android Spinner (android.widget.Spinner) is an interactive UI widget that provides a quick way to select one value from a set. In its default resting state, a Spinner displays its currently selected item. When tapped by the user, it opens a popup modal dialog or a dropdown menu displaying all available items from which the user can make a selection.

Key characteristics:

  • Belongs to android.widget.Spinner.
  • Subclass of AdapterView, meaning its content is not added directly as XML child views, but is generated dynamically through an Adapter.
  • Supports display modes such as dropdown (anchored list) or dialog (centered dialog modal).

2.2 What is an Adapter?

In Android, UI widgets such as Spinner, ListView, and RecyclerView only know how to render native Android View instances (such as TextView or ImageView). They cannot directly display raw Java/Kotlin data types such as String, Integer, or custom model objects.

The Adapter pattern acts as an intermediary bridge or translator between a data source and an AdapterView. It is responsible for:

  1. Holding the dataset: Managing references to the underlying collection (array, List, database cursor).
  2. View Inflation & Recycling: Inflating a layout resource for each individual item.
  3. Data Binding: Extracting each data element and binding its fields into the corresponding UI elements of the inflated view.
  4. Providing views to the container: Feeding the fully constructed Views to the Spinner or list.

2.3 The ArrayAdapter

ArrayAdapter is a standard Android implementation of the Adapter interface tailored specifically for array or List-backed datasets. For each item in the array, ArrayAdapter calls .toString() on the object and populates a single TextView defined by a designated layout resource.

3.2 Data Source Definition & Adapter Binding (DataInput.java)

public class DataInput extends AppCompatActivity {
    // 1. Dataset: The raw options to display in the dropdown
    private String[] status = {"full-time", "part-time", "student", "other"};

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        EdgeToEdge.enable(this);
        setContentView(R.layout.activity_main);

        // 2. Locate the Spinner UI widget
        Spinner sp = findViewById(R.id.spinner);

        // 3. Instantiate the ArrayAdapter:
        //    - this: Context needed to inflate layout resources
        //    - android.R.layout.simple_spinner_item: Layout for the collapsed/selected item
        //    - status: The array of data
        ArrayAdapter<String> adapter = new ArrayAdapter<>(
                this,
                android.R.layout.simple_spinner_item,
                status
        );

        // 4. Specify the dropdown view template used when the menu expands
        adapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item);

        // 5. Attach the adapter to the Spinner widget
        sp.setAdapter(adapter);
    }
}

3.3 Selection Retrieval and Form Validation

private void displayNextAlert() {
    // Guard clause: enforce Terms and Conditions checkbox agreement
    CheckBox agreeTerms = findViewById(R.id.chkAgreeTerms);
    if (!agreeTerms.isChecked()) {
        popupToast("Sorry, you need to agreed with the teams even though you don't know what they are");
        return;
    }

    // Retrieve input values
    EditText nameInput = findViewById(R.id.editTextName);
    DatePicker dobInput = findViewById(R.id.DatePickerDOB);
    EditText emailInput = findViewById(R.id.editTextEmail);
    Spinner sp = findViewById(R.id.spinner);

    String strName = nameInput.getText().toString();
    String strDOB = dobInput.getDayOfMonth() + "/" + (dobInput.getMonth() + 1) + "/" + dobInput.getYear();
    String strEmail = emailInput.getText().toString();

    // Adapter position lookup: query the selected index and map back to data array
    int row = sp.getSelectedItemPosition();
    String strStatus = status[row];

    // Display summary via AlertDialog
    new AlertDialog.Builder(this)
            .setTitle("Details Entered")
            .setMessage("Details entered\n"
                    + strName + "\n" + strDOB + "\n" + strEmail + "\n" + strStatus)
            .setNeutralButton("Back", (dialog, which) -> {
                // Dismiss dialog
            })
            .show();
}
